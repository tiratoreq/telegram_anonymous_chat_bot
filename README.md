# Telegram Anonymous Chat Bot

Анонимный чат-бот для Telegram: находит случайного собеседника и позволяет обмениваться текстовыми сообщениями, не раскрывая личности, username и id.

Бот написан на Python с чистой архитектурой (handlers / services / storage / config), конфигурацией через `.env` и базовой защитой от спама.

## Возможности

-  `/find` — встать в очередь и найти случайного собеседника
-  Обмен текстовыми сообщениями через бота (личности и id не раскрываются)
-  `/stop` — завершить текущий диалог и вернуться в меню
-  `/next` — завершить диалог и сразу искать нового собеседника
-  Не более одного активного диалога одновременно
-  Уведомление второму пользователю, если собеседник вышел
-  История переписки не сохраняется после завершения диалога
-  Rate limiting, ограничение длины сообщений, запрет спама, обработка ошибок
-  Админ-команда блокировки пользователя по id

## Стек

- Python 3.11
- aiogram 3.x
- SQLite (очередь, активные пары, блокировки)
- Redis (rate limiting, временные состояния)
- python-dotenv / pydantic-settings для конфигурации

## Архитектура

Проект разделён на слои, чтобы бизнес-логику можно было тестировать и менять независимо от Telegram API.
